Information Architecture
Home Entry Point — Carousel
홈 화면의 KOL Insight 섹션은 캐러셀 형태로 최신 이슈를 노출합니다. 유저가 스크롤하다 자연스럽게 마주치는 위치에 배치되어 탐색 흐름을 유도합니다.
New
KOL Insight 섹션 추가
홈 피드에 KOL 이슈 캐러셀 영역을 신규 배치. Trending 아래, Market Tabs 위에 위치하여 시장 맥락 파악 후 자연스럽게 인사이트로 진입하도록 설계.
UI
캐러셀 카드 구성
유저가 카드만 보고도 이슈의 성격과 규모를 즉시 판단할 수 있도록 구성.
  • 1행 — 뱃지 클러스터: Issue 번호 뱃지, 센티먼트 뱃지, Hot 뱃지를 나란히 배치
    • Issue 번호 뱃지 — 이슈의 순번을 표시 (Issue 1, 2, 3)
    • 센티먼트 뱃지 — Positive(👍) 또는 Negative(👎)로 이슈의 방향성을 색상과 아이콘으로 즉시 전달
    • Hot 뱃지 — 급등하는 이슈에 🔥 아이콘을 표시하여 긴급도를 시각화
  • 2행 — 타이틀: 이슈의 핵심 내용을 1줄로 요약 (1줄 제한)
  • 3행 — 메타 정보: 관련 심볼 아이콘(최대 2개) + 멘션 수로 이슈의 영향 범위를 표시
이슈 정렬 기준은 멘션 수 내림차순. 수집 주기(24h/6h) 내 가장 많이 언급된 이슈가 상위에 노출. 캐러셀은 최대 3장의 카드만 노출. 마지막 슬라이드에는 잔여 이슈 수를 표시하는 CTA 카드를 배치하여 리스트 전체 보기로의 전환을 유도.
UX Policy — 정보 인지 흐름
  • 유저는 홈에서 스크롤하며 Trending → KOL Insight 순서로 시장 컨텍스트를 파악함
  • 캐러셀은 프로모션 배너와 동일한 패턴(풀 너비 카드, 도트 인디케이터, 스냅) 적용 — 플랫폼이 유저에게 전달하는 콘텐츠라는 일관된 흐름 유지
  • 단, 자동 롤링은 적용하지 않음 — KOL Insight는 유저가 직접 골라 읽는 콘텐츠이므로 자동 전환이 읽기를 방해함. 수동 스와이프만 지원
  • 각 카드의 센티먼트 뱃지(색상)가 가장 먼저 시선을 끌어 긍정/부정을 즉시 판단 가능
  • "See all" 텍스트 버튼은 전체 리스트로의 진입점 역할
Information Architecture
List View — 전체 이슈 목록
모든 KOL 이슈를 세로 리스트로 나열. 각 카드는 엔트리포인트 캐러셀과 동일한 정보 구조를 유지하되, 타이틀을 말줄임 없이 전체 표시하여 더 많은 컨텍스트를 전달합니다. 정렬 기준은 캐러셀과 동일하게 멘션 수 내림차순.
UI
리스트 카드 구성
엔트리포인트 캐러셀과 동일한 정보 구조를 세로 리스트 형태로 표시.
  • 1행 — 뱃지 클러스터: Issue 번호 뱃지, 센티먼트 뱃지, Hot 뱃지를 나란히 배치
    • Issue 번호 뱃지 — 이슈의 순번을 표시 (Issue 1, 2, 3…)
    • 센티먼트 뱃지 — Positive(👍) 또는 Negative(👎)로 이슈의 방향성을 색상과 아이콘으로 즉시 전달
    • Hot 뱃지 — 급등하는 이슈에 🔥 아이콘을 표시하여 긴급도를 시각화
  • 2행 — 타이틀: 이슈의 핵심 내용을 말줄임 없이 전체 표시 (엔트리포인트는 1줄 제한, 리스트에서는 전체 노출)
  • 3행 — 메타 정보: 관련 심볼 아이콘(최대 2개) + 멘션 수로 이슈의 영향 범위를 표시
UX Policy — 스캔 패턴
  • 유저는 리스트를 위에서 아래로 빠르게 스캔하며, Issue 번호 → 센티먼트 뱃지 → 제목 순서로 정보를 처리
  • 카드 좌측의 뱃지 클러스터가 앵커 역할을 하여 시선의 시작점을 고정
  • 타임스탬프("15m ago")는 데이터의 신선도를 즉각 전달하여 신뢰를 형성
Information Architecture
Detail View — 이슈 상세
개별 이슈의 전체 맥락을 전달하는 화면. 제목 → 에디토리얼 요약 → 시그널 뱃지 → 관련 자산 순서로 점진적으로 깊은 정보를 제공합니다.
UI
디테일 화면 구성
유저가 위에서 아래로 읽으며 점진적으로 깊은 정보를 소비하는 구조.
  • 1행 — 뱃지 + 타임스탬프: Issue 번호 뱃지, 센티먼트 뱃지, Hot 뱃지(🔥)를 좌측에, 발행 시간(14m ago)을 우측에 배치
  • 2행 — 타이틀: 이슈의 핵심 주장을 전체 텍스트로 표시
  • 3행 — 에디토리얼: KOL들의 의견을 중립적으로 요약한 읽기 전용 블록. 좌측 보더라인으로 인용문 스타일을 적용하여 본문과 구분. 하단에 출처 갯수(N sources)를 표시하여 정보의 신뢰도를 전달
  • 4행 — 시그널 뱃지 클러스터: 센티먼트, 멘션 수, Buzz 상태를 뱃지 형태로 나란히 배치하여 이슈의 정량적 요약을 한눈에 전달
    • Positive 👍 — 긍정적 여론 · Negative 👎 — 부정적 여론 · Mixed tone — 의견이 섞여 있음
    • Buzz growing — 화제성이 커지고 있음 · Buzz steady — 꾸준히 얘기되고 있음
  • 5행 — Mentions and Movement: 관련 자산의 멘션 수와 7일 가격 변동을 표시. 이슈가 실제 시장에 미치는 영향을 수치로 연결
하단에 "See other issues" CTA로 리스트 복귀를 유도하여 탐색 루프를 완성. 면책조항("Not investment advice")을 통해 정보의 성격을 명확히 고지.
UX Policy — 행동 유도
  • 에디토리얼은 읽기 전용 콘텐츠로, 유저가 판단의 근거로 활용할 수 있는 중립적 요약을 제공
  • "Sources" 링크로 원문 접근 가능성을 보장하여 정보의 신뢰도를 높임
  • 관련 자산 row의 화살표(chevron)가 해당 심볼 트레이딩 화면으로의 전환을 암시
  • "See other issues" CTA로 리스트 복귀를 유도하여 탐색 루프를 완성
  • 하단 면책조항("Not investment advice")을 통해 정보의 성격을 명확히 고지
